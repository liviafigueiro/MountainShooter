# Mountain Shooter

Projeto de jogo desenvolvido durante a disciplina de Linguagem de Programação Aplicada, com base em uma proposta guiada pelo professor. A atividade consistia em acompanhar a construção do jogo para aprendizado prático dos conceitos e, posteriormente, desenvolver uma versão própria aplicando os conhecimentos adquiridos.

O projeto foi criado com foco no desenvolvimento da lógica de programação, manipulação de eventos, estruturas de repetição, organização de código e interação com elementos gráficos.

## Objetivos do projeto
- Praticar conceitos de programação
- Desenvolver raciocínio lógico
- Aplicar estruturas condicionais e repetição
- Trabalhar interação do jogador com o ambiente do jogo
- Compreender a organização de um projeto de software na prática
